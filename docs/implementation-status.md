# Implementation-status inventory

This page distinguishes **functioning** capabilities (executable and covered by the cited tests), **mocked** ones (the interface and checks run, but a component is simulated or supplied by hand) and **planned** ones (described in the manuscript or docs, not implemented).
It is generated from [`implementation-status.yaml`](implementation-status.yaml) by `scale status --format markdown`; `test_inventory_references_real_tests` checks that every functioning entry cites tests that exist.

Release **v0.1.0** · tool **0.1.0** · environment used for the included tests: Python 3.13 and 3.10 on macOS; CI on Python 3.10–3.13 (Ubuntu).
