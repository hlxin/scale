# Decision record 0001 — SCALE 0.1.0: one framework, one schema version, a clean start

- **Status:** decided
- **Date:** 2026-10-08
- **Kind:** the repository, the framework's name and scope, its versioning, and the decisions carried over from the
  work this repository continues; the content of the schema is unchanged by this record
- **Decided by:** Hongliang Xin (hlxin), the owner, in a Claude Code session on 2026-10-08; recorded by the agent on
  his instruction.

## Context

SCALE was developed in the SCALE Consortium's schema repository (the consortium schema repository) up to commit
79b4fe4, as a catalysis-only "atlas"
whose science kernel and catalysis files carried separate version numbers (the catalysis graph schema had reached
0.5.0 on a kernel 0.2.0, with its earlier versions frozen beside it, a first release, an archive of earlier releases
and nineteen decision records). The owner decided to continue the work in his own repository, `hlxin/scale`, which he
will share with others, as a general framework, with one version number for the whole schema, numbered from the
beginning. This record states the decisions that hold from now on; the earlier records, releases, frozen versions and
proposals stay in the consortium schema repository.

## Decision

1. **Repository and name.** The repository is `github.com/hlxin/scale`, a personal repository of its owner, Hongliang
   Xin. SCALE stands for **Shared Concepts, Attributes, and Links with Evidence: one shared framework for
   evidence-backed scientific knowledge graphs across domains.** The Python package stays `scale-schema` (the names
   `scale` and `schema` are taken on PyPI), with the commands `scale` and `scale-schema`.
   Implemented in: [README.md](../../README.md), [pyproject.toml](../../pyproject.toml),
   [tools/scale/layout.py](../../tools/layout.py) (`REPOSITORY_URL`), [CITATION.cff](../../CITATION.cff).
2. **Two layers.** The schema has two layers: the science kernel (`core/`), the general base layer of the method of
   science, and the domains, each building on the kernel through its own graph schema manifest. Catalysis is the first
   domain and, for now, the only one; its folder is `domain/` and its identifier stays `catalysis`
   (`follows_domains`, `DOMAIN.yaml`, `scale domains`). Catalysis is the founding domain (`founding: true`) and is
   `status: stable` from 0.1.0, accepted by this record (its `decision_record`); every concept in it is still
   `maturity: provisional`, and as a founding domain its unmet stewardship targets are warnings. There is no
   repository-wide composition and no third layer. A second domain would revisit the one-folder layout and how the one
   version spans several domains.
   Implemented in: [core/](../../core/README.md), [domain/](../../domain/README.md),
   [domain/DOMAIN.yaml](../../domain/DOMAIN.yaml),
   [docs/architecture.md](../architecture.md), [tools/scale/pgraph_schema.py](../../tools/pgraph_schema.py),
   [tools/scale/domains.py](../../tools/domains.py).
3. **One version, numbered from 0.1.0.** The schema has one version number for the kernel and the catalysis domain
   together: the `version` of the catalysis manifest, `domain/graph/scale-graph.yaml`. The kernel file and the
   catalysis file carry none (a part that states one does not load); `core/CORE.yaml`, `domain/DOMAIN.yaml`,
   `scale-release.yaml` (`schema_version`) and the kernel-only example manifest state the same number, and
   `scale domains check` requires them to agree. Every applied proposal raises it, whichever file it changes; applying
   one freezes the version it replaces (the catalysis manifest and file in `domain/graph/frozen/`, the kernel of that
   version in `core/graph/frozen/kernel-<version>.yaml`). Today's content is **0.1.0**; its spec digest is recorded in
   the [README](../../README.md#schema-versions) and the [CHANGELOG](../../CHANGELOG.md). A version number names a
   schema only within this numbering: a reader binds a schema by its spec digest (`lineage: scale`), and a document
   pinning a version this repository does not hold is reported as such, never read under another version of the same
   number.
   Implemented in: [tools/scale/pgraph.py](../../tools/pgraph.py) (`spec_document`, `identify`, `pinned`),
   `tools/scale/pgraph_proposal.py` (`apply`, `VERSION_FILES`),
   [tools/scale/releases.py](../../tools/releases.py), `scale graph spec --expect`.
4. **A clean start.** The new repository carries no earlier frozen versions, releases, proposals, migration steps,
   driving-force profiles of earlier versions or decision records; their content is today's 0.1.0. The public
   catalysis example documents and fixtures were moved to today's content (with the tools of the time, where they
   pinned an earlier version) and re-pinned to 0.1.0; the five science-kernel cases already pinned 0.1.0 and are
   unchanged. The public synthetic fixtures of the applied proposals that added the catalyst states and contexts and
   the source lifecycle (passing documents and counterexamples) are kept as test fixtures, re-pinned to 0.1.0, since
   the concepts they test are today's. No release has been built yet; the first will be `v0.1.0`. The skills restart
   their numbering at 0.1.0 as well. The general tools come along; among them, the check of scanned-page readings that
   the consortium schema repository's methanol corpus tool applied (a reading of a page image that OCR does not
   confirm in its region needs a matching, independent second reading; every value is backed by a transcription or
   quote; each agreement names its OCR engine) is now a general command, `scale pages`, with its tests on synthetic
   pages. Not carried: the tools that served only that repository's two restricted example corpora (the methanol
   corpus's brief, assembly, scoping and bundle commands, corpus freezer, record-format converters and workbook tools;
   another corpus's curation tools), their query plans and READMEs, and two unapplied proposals (stability maps and
   the order of phenomena in the kernel; activity in a catalyst state and reaction pathways in catalysis). They served
   project data that may not be published, which is kept in a separate private data repository; the tooling stays in
   the consortium schema repository at 79b4fe4. Leaving these tools out is the agent's reading of the owner's
   instruction that this repository carry no restricted-data integration; any of them can be ported later as a general
   command, as the scanned-page check was. The two proposals' themes are open work
   ([domain/ROADMAP.md](../../domain/ROADMAP.md)).
   Implemented in: [tools/scale/pagereading.py](../../tools/pagereading.py),
   [docs/curation.md](../curation.md#reading-scanned-pages-two-readers), [CHANGELOG.md](../../CHANGELOG.md),
   [tools/tests/fixtures/catalyst-states/](../../tools/tests/fixtures/catalyst-states/README.md),
   [tools/tests/fixtures/source-lifecycle/](../../tools/tests/fixtures/source-lifecycle/README.md).
5. **One data format.** SCALE reads and writes scale-graph documents only (node-link JSON, `schema: scale-graph`), each
   pinning the schema version it follows.
   Implemented in: [docs/architecture.md](../architecture.md#document-model), `scale graph validate`.
6. **Evidence and the copyright cap.** Every node and edge that states something carries evidence: the source, a
   locator, its kind and a short verbatim quote. For sources in copyright or restricted, each quoted text is at most
   300 characters and the distinct quoted characters of one source at most 4,000 and 10 % of its text when known;
   `rights.yaml` records each source's rights (a source without an entry counts as in copyright); text beyond the cap
   is withheld as a fingerprint that anyone holding the source can restore. Claims are written in the curator's own
   words. `scale check` enforces the cap.
   Implemented in: [tools/scale/rights.py](../../tools/rights.py), `scale evidence report | cap | rehydrate`,
   [docs/curation.md](../curation.md).
7. **Licences.** Code is MIT; the vocabulary, curated records, examples, documentation, governance texts, the skills'
   texts and the releases are CC-BY-4.0; third-party material stays under its owners' terms and is listed in `NOTICE`.
   `REUSE.toml` gives every file its licence by path and `reuse lint` is a step of `scale check`. Contributions come in
   under the licence of their path.
   Implemented in: [REUSE.toml](../../REUSE.toml), [LICENSES/](../../LICENSES), [NOTICE](../../NOTICE),
   [governance/licensing.md](../../governance/licensing.md).
8. **No project data committed.** Every committed document is public and says so (`access: public`); curated project
   data that is not cleared for publication is never committed. The tools may read inputs that may not be committed
   from an optional restricted copy that only an environment variable names (no default location, no specific
   repository); a proposal check that reads such inputs writes its full reports there and public summaries in the
   repository.
   Implemented in: `scale evidence access` (a step of `scale check`), [tools/scale/layout.py](../../tools/layout.py)
   (`restricted_root`, `locate`), `tools/scale/pgraph_proposal.py`.
9. **Schema changes through proposals.** The schema changes only through a proposal: operations on the schema files,
   fixtures that must pass and counterexamples that must fail for a stated reason, the migration of assessed
   documents, the competency questions re-run, new concepts entering as provisional, a semantic diff and its tier; a
   breaking change needs a migration step and a decision record. A proposal is named by a six-digit number, global
   across the kernel and every domain. Its pull request is reviewed like every change: two approving reviews from
   reviewers other than the author once the two reviewer seats are filled; until then the owner merges under the
   bootstrap rule, which the decision record says. Agents draft; people approve, merge and apply.
   Implemented in: [tools/skills/evolve-schema/SKILL.md](../../skills/evolve-schema/SKILL.md),
   `tools/scale/pgraph_proposal.py`,
   `tools/scale/apply_merged.py`,
   [governance/review-policy.yaml](../../governance/review-policy.yaml),
   [governance/GOVERNANCE.md](../../governance/GOVERNANCE.md), [domain/competency/](../../domain/competency).
   Superseded later: proposals were retired; a schema change is an ordinary pull request that raises the version
   itself (`scale schema bump`, `scale schema check`), approved by one person ([GOVERNANCE.md](../../governance/GOVERNANCE.md)).
10. **The source lifecycle.** A source's publication status is derived from notice links, never typed: a notice is a
    Source of its own that `RETRACTS` (with its scope) or `UPDATES` (by `update_type`) another; `status_check` records
    who looked for notices, when and how. Records resting on retracted sources are flagged, never rewritten or deleted;
    queries leave out what rests only on retracted sources unless a plan sets `include_retracted`. No tool checks
    registries yet: a status check is a person's (open work: [domain/ROADMAP.md](../../domain/ROADMAP.md), "Source
    lifecycle follow-ups").
    Implemented in: [core/graph/kernel.yaml](../../core/graph/kernel.yaml),
    [tools/scale/lifecycle.py](../../tools/lifecycle.py), [tools/scale/pgraph_query.py](../../tools/pgraph_query.py),
    [domain/competency/cq-05-retracted-sources.yaml](../../domain/competency/cq-05-retracted-sources.yaml).
11. **Units: compared exactly, converted later.** The schema performs no unit conversion and a value keeps the unit as
    reported. A numeric query filter states its unit and compares only values in that unit, spelled the same (case
    included), on the basis it states; every other value is left out with its reason and counted. Unit conversion and
    basis reading wait for a units proposal.
    Implemented in: [tools/scale/pgraph_query.py](../../tools/pgraph_query.py), [docs/querying.md](../querying.md).
12. **Access fails closed for answers.** Every query result and search result carries the least open effective
    stewardship anywhere in the queried document; no part of an answer is read as more open. A missing or malformed
    access reads as `institution`, an embargo is read on the earlier of the local and the UTC date, and a filtered view
    (`scale graph filter --public | --as`) or a kg-bundle declares the audience it is for and withholds what that
    audience may not see.
    Implemented in: [tools/scale/pgraph.py](../../tools/pgraph.py) (`visible`, `filter_for`, `restrict_to`),
    [tools/scale/pgraph_query.py](../../tools/pgraph_query.py) (`document_access`),
    [tools/scale/kgbundle.py](../../tools/kgbundle.py).
13. **No curator attribution.** SCALE's procedures and tools record no curator of a record: a curation records who
    contributed data at the level of stewardship (`contributed_by`: institutions and projects) and what the source
    says, and leaves the kernel's optional stewardship field `curated_by` empty; review and curation-run fields are
    not invented for records, and a kg-bundle's producer and extraction fields name no curator (the people
    and institutions a bundle exports are those its sources report, such as authors and assignees). Credit for work
    on SCALE is recorded in `CORE.yaml` and `DOMAIN.yaml` (`maintainers`, `contributors`) and in release manifests.
    Implemented in: [skills/curate-corpus/SKILL.md](../../skills/curate-corpus/SKILL.md) (then curate-dataset, now its section A data file),
    [tools/scale/kgbundle.py](../../tools/kgbundle.py),
    [governance/credit-and-authorship.md](../../governance/credit-and-authorship.md).

## Consequences

- The repository starts with one commit ("SCALE 0.1.0"). Its tests cover the behaviour of today's tools on the one
  version line; tests that only exercised the history of the consortium schema repository, or needed its restricted
  data, were not carried.
- The decisions above replace the consortium schema repository's decision records for this repository. Later decision records
  are numbered from 0002; `scale proposal decide` writes one per applied proposal.
- Governance is that of a personal repository: the owner is the code owner of every path; two reviewer seats are
  placeholders until people join ([governance/GOVERNANCE.md](../../governance/GOVERNANCE.md)).
