Curate a publication

A PDF, a DOI, or both. A model reads the paper and records it as a graph under SCALE Catalysis; the SCALE tools check every record, and every quote against the paper's own text. It takes a few minutes.

With a DOI alone, only an open-access copy can be fetched. Behind a paywall, upload the PDF you can read through your library.

What is shared, and with whom

  • To curate, the PDF or DOI goes to the SCALE service, which sends the paper's text to Anthropic's Claude API to read it.
  • The paper is kept only to curate it again when SCALE's schema changes, so nobody has to upload it twice: the PDF and its text, always for a paper under an open licence, and for any other paper only if you tick the box below; otherwise the service deletes them when the job ends. A kept paper is private to the service, never published, and you can withdraw your agreement at any time, which deletes it.
  • The graph comes back to you only. Nothing is published unless you contribute it.
  • Contributing is a separate click. It opens a public pull request on github.com/hlxin/scale that names your GitHub login, and once it is merged your login joins the contributors' leaderboard. The records are shared under CC BY 4.0; they quote no text of a paper under copyright. A person reviews it before it joins catal-commons.
  • To curate, the PDF or DOI goes to the computer that runs the SCALE service. There Claude Code (Anthropic's Claude) reads the paper's text in a folder of its own, with no network and no other files, and records it as a graph; the SCALE tools check every quote against the text.
  • Nothing is kept. The PDF and its text are deleted from that computer as soon as the paper is curated, or when curating it fails.
  • The pull request opens by itself. Once the graph passes the checks, the SCALE bot opens a public pull request on github.com/hlxin/scale that names your GitHub login, and once it is merged your login joins the contributors' leaderboard. The records are shared under CC BY 4.0; they quote no text of a paper under copyright. A person reviews it before it joins catal-commons.
  • No API key, no cost to you. Signing in with GitHub only tells the service your login, so it can keep use within its daily budget.
  • Your questions count toward others' credit. When you are signed in, the leaderboard counts which contributions answered you (a digest of your login and the day, never the question).
  • A rights holder can ask for a paper's records or kept copy to be removed by opening an issue.

Contributors to catal-commons

Everyone who has added a paper to catal-commons, SCALE's shared catalysis graph, scored by the knowledge they added (evidence-backed triples) and by how often it answers other people's questions. Each entry is a merged pull request, read from contributors.yaml.

How scoring works

The rules are one function, tools/commons.py; changing them is a pull request.
